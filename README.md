# Gridiron Pulse 🏈

Welcome to **Gridiron Pulse**, a responsive front-end website designed to track and display the latest news, schedules, and headlines across the NFL.

## Features
- **Live News Ticker:** Displays real-time league notifications utilizing CSS marquee animations.
- **Responsive Layout:** Automatically scales across desktop, tablet, and mobile displays using CSS Grid.
- **Modern Theme:** Uses a clean, sports-centric slate and neon blue dark mode UI.

## File Structure
- `index.html` - Site structure and content framework
- `style.css` - Visual presentation layer and animations
